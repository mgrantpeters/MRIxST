# *A molecular map of the living human brain from quantitative MRI*

Can we infer molecular information from quantitative MRI imaging using spatially resolved transcriptomics? This is the question we set out to answer in our pre-print (https://doi.org/10.1101/2025.09.24.678316). This repository contains all the code relating to this project, including the data generated specifically for this project and instructions of how to access other datasets. 

## Respository contents
### code
All code for reproducing results, statistics, and plots in the paper. These scripts contain a combination of scripts in R, python and jupyter notebooks for interactive analysis and visualisation. All analyses were primarily run on a high performance computing cluster and have not been tested on a local machine. In particular, all analyses relating to GO pathways (especially filtration of GO pathways and spatial pathway scoring) have long running times of up to several days and should be run as a submitted job on an HPC. 

- 00-prepare_GO
  - Fetch and prepare GO pathways (myelin, iron, lipid, inflammation) for SRT analyses
- 01-4layers_withendo
  - Partition 4 layers in SRT data, filter GO pathways for inclusion, cell type deconvolution processing and score pathways on SRT
- 02-4layers_qMRIvsST_withendo
  - control qMRI vs SRT correlation, LOOCV, and Cook's distance analyses
- 03-4layers_qMRI_PDvsCtrl
  - PD vs control qMRI group analysis 
- 04a-visualisations
  - Wrangle results of correlations and visualise
- 04b-4layers_PDpredictions_withendo
  - PD qMRI-derived SRT score projections 
- 06_validation_lipids
  - Analysis of lipid characterisation data (glicosphingolipids and glucosylceramide)
- 07_spatialDLPFC_registration
  - Comparison of spatial domains in this study to conventional cellularly-defined cortical layers 1-6
- 08_transcriptomics
  - Visualisation of single nucleus RNA sequencing data (Control and Braak 3/4 PD cortex)
- 09_SupplementaryTables
  - Generation of supplementary tables

## Accessing other datasets
We additionally make use of datasets associated with other projects which are listed below: 

*Spatially-resolved transcriptomics data from control dorsolateral prefrontal cortex* (original publication available in Science, DOI: 10.1126/science.adh1938). This dataset as well as paired single nucleus RNA-sequencing data are publicly available and can be downloaded through the spatialLIBD R package (DOI: 10.18129/B9.bioc.spatialLIBD).

*Single nucleus RNA-sequencing data for Braak stage 3/4 Parkinson's disease and controls* (original manuscript on bioRxiv, DOI: 10.1101/2025.08.25.671921). This dataset has been submitted to the CRN cloud for publication and will be made available on the CRN cloud (https://cloud.parkinsonsroadmap.org/).
