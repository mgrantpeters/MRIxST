The files within this folder were fetched from the amigo web interface for gene ontologies. Keywords relating to qMRI metrics were selected and searched. The ontologies associated with these keywords were downloaded as a tsv and converted to .csv.
Search keywords: 
 - Iron
 - Lipid
 - Myelin
 - Mineral
 - Inflammation
 - Cell death

Although many of the pathways have no relation to the brain, these were kept as negative controls for downstream analyses.
